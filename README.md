# ConectaEmpresa

## Sistema de Gestão de RH e Controle de Ponto

O **ConectaEmpresa** é um sistema web desenvolvido para auxiliar pequenas e médias empresas na gestão de recursos humanos, funcionários e controle de ponto.

### 🌐 Acessar o ConectaEmpresa

**[Entrar no ConectaEmpresa](https://conectaempresa.netlify.app/)**

### 📋 Recursos

- Controle de ponto eletrônico
- Gestão de funcionários
- Gestão de empresas
- Controle de entrada, pausa e retorno
- Administração de usuários
- Diferentes níveis de acesso
- Recursos para gestão de RH

### 🔐 Segurança

O sistema utiliza autenticação e controle de acesso para separar os dados das diferentes empresas.

### 🛠️ Tecnologias

- JavaScript
- HTML
- CSS
- Supabase
- Netlify

### 🎯 Objetivo

O objetivo do ConectaEmpresa é oferecer uma solução web para facilitar a administração de funcionários e processos de recursos humanos em pequenas e médias empresas.
